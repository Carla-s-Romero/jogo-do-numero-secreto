# Secret Number Game

Jogo de adivinhação desenvolvido com HTML, CSS e JavaScript como parte de um projeto da formação Alura em parceria com o programa ONE.

O objetivo do jogo é descobrir um número secreto gerado aleatoriamente pelo sistema. O jogador deve inserir um número entre 1 e 10 e realizar tentativas até encontrar o número correto.

## Sobre o Projeto

O projeto foi desenvolvido como uma aplicação prática para exercitar fundamentos de desenvolvimento web e lógica de programação com JavaScript.

Durante o desenvolvimento, foram trabalhados conceitos como geração de números aleatórios, manipulação do DOM, eventos de interação com o usuário, funções, condicionais e atualização dinâmica do conteúdo da página.

## Funcionalidades

* Geração aleatória de um número secreto
* Entrada de números entre 1 e 10
* Verificação das tentativas do jogador
* Mensagens de feedback durante o jogo
* Contagem de tentativas
* Botão para iniciar uma nova partida
* Interface responsiva
* Interação dinâmica utilizando JavaScript

## Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/Carla-s-Romero/Secret_number_game.git
```

### 2. Acesse a pasta do projeto

```bash
cd Secret_number_game
```

### 3. Execute a aplicação

Por ser uma aplicação desenvolvida com HTML, CSS e JavaScript puro, basta abrir o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão Live Server no Visual Studio Code para executar o projeto durante o desenvolvimento.

## Como Jogar

1. Escolha um número entre 1 e 10.
2. Digite o número no campo de entrada.
3. Clique em **Chutar**.
4. Confira o resultado da tentativa.
5. Continue tentando até descobrir o número secreto.
6. Utilize **Novo jogo** para iniciar uma nova partida.
